Crewnox

Elevating the brand experience of the Crewnox Innovation Labs website: a portfolio that carries service breadth, case-study depth and a clear route to enquiry.

Type
Brand and product design
Client
Crewnox Innovation Labs (self-initiated)
Scope
Homepage, portfolio system, enquiry flow, theming
Delivered
Development-ready UI, light and dark
Tools
Figma

The brief

Elevate the brand experience of the Crewnox website. The scope was a homepage, a portfolio system, an enquiry flow and theming, with development-ready UI in light and dark as the finish line.

The problem

The studio's own site had not kept pace with its client work. It was the one project the studio kept putting last. The portfolio had to show service breadth, case-study depth and a route to enquiry, without feeling like a generic template.

The process

Three stages, one file.

  1. 01

    Explore openly

    The work started loose. A moodboard set the tone before any UI was drawn, and the design phase was deliberately messy.

    Output: moodboard and early directions

  2. 02

    Build a resource library

    Colours, type, cards and components were gathered into one shared library, so every later screen drew from the same parts.

    Output: palette, components, themes

  3. 03

    Make it development-ready

    The final stage covered the edge cases a build would hit, such as categories with no live work, and finished both light and dark themes.

    Output: development-ready UI, light and dark

What shipped

Screens delivered

The intended path runs from the homepage to a sub-category or All Projects, then to a project, then to the enquiry form and its confirmation.

  • Homepage in light and dark theme
  • Sub-category landing pages for each service
  • A filterable All Projects portfolio grid
  • Enquiry form with a confirmation state
  • A blank state for categories with no live work
  • A mobile-responsive pass across every screen

Outcomes

One brand system

Themes, heroes and grids all trace back to a single shared resource library.

A shorter path to enquiry

Every route leads to one low-friction form and a confirmed next step.

Responsive by design

Mobile was drafted alongside desktop, not added at the end.

No dead ends

Empty categories get a blank state that reassures rather than stalls.
