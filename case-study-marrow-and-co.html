Case study · Web Design · Hospitality · Concept

Marrow & Co.

An editorial website for a neighbourhood restaurant, where the menu reads like a short story.

Type
Web design
Timeline
7 weeks (concept)
Role
Creative direction, web UX/UI, handoff
Shipped
Responsive site design and developer handoff

This is a fictional concept project. There is no real client, and nothing here describes real results.

The challenge

Most restaurant sites are a PDF menu and a booking widget bolted on. Marrow & Co. wanted a site that carried the same slow, generous feeling as the dining room, and made reserving a table effortless.

The approach

Large type, slow pacing and a reservation path that never leaves the first screen. The menu is written as short paragraphs so the page reads as a story, and the layout holds from phone to widescreen.

The process

Four steps, one thread.

  1. 01

    Discover

    We read the menu aloud and noted how the kitchen talks about food. That voice, warm and a little wry, became the writing guide for the site.

    Output: voice notes and content inventory

  2. 02

    Define

    We prioritised three jobs for the site: see the menu, reserve a table, find the door. Everything else was secondary and moved to the footer.

    Output: site map and page priorities

  3. 03

    Design

    Type-led layouts first, with imagery added only where it earned its place. Desktop and mobile were designed together, not one after the other.

    Output: responsive page designs

  4. 04

    Deliver

    A handoff pack with spacing, type scale, breakpoints and every interaction state specified, so a developer never has to guess.

    Output: handoff specification

What shipped

Screens shipped

Key pages across desktop and mobile.

What we took from it

Type can carry a page

With strong typography, the site needed very little imagery to feel finished.

Design both sizes at once

Mobile was a first-class layout, not a collapsed desktop.

Spec every state

Handoff quality is decided by error and empty states.
